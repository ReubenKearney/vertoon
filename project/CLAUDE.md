# WORDWERX — historical handoff bundle (not the codebase)

⚠️ **This `project/` folder is a historical design-handoff bundle, not the app.**

It was exported from Claude Design and describes the *original prototype*: a
single `WORDWERX.html` built with inline React + Babel, `app/*.jsx` files, and
`window.*` sharing. **That prototype no longer exists.** The app was rebuilt as a
Vite + React + TypeScript project.

- **The real app:** [`../wordwerx/`](../wordwerx/)
- **Start here:** [`../wordwerx/README.md`](../wordwerx/README.md)
- **Agent guide:** [`../wordwerx/CLAUDE.md`](../wordwerx/CLAUDE.md)

The other files here — `HANDOFF.md`, `VISUAL_DEV_HANDOFF.md`, `README.md`, and
`chats/` — are kept only as a record of the original design phase. Don't
implement against them.
